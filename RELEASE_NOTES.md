# Release v0.5 — research-ready local foundation

**AI-Powered Market Intelligence & Document Analysis using RAG + HPC on AWS**

This archive is an organized **local-first engineering project** for a fourth-year demonstration. It does **not** include any deployed cloud/database infrastructure.

## New, real improvements

- Portable Windows and Ubuntu setup/run scripts, beginner quick start, project-relative data defaults and optional MPI dependency group.
- Four-page Market Atlas UI with source-quality charts, first-run synthetic practice import, workload preview and preserved code/UI separation.
- Source-grounded extractive answers without pretending an LLM has generated text.
- Full top-k validation and memory-safe distributed clustering equivalence.
- Genuine MPI source with rank evidence; local launcher verifies calculated outputs against the sequential baseline.
- MPI scaling suite for multiple dataset sizes and rank counts, using actual measurements only.
- Performance metadata for work units/sec, rank CPU seconds and memory high-water marks on supported operating systems.
- Academic blueprint, experiment protocol, data provenance guide, and Slurm templates for later review.
